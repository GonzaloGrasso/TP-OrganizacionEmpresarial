* /resultados: Guarda la salida visual obligatoria grafico_ventas.png.

## Instrucciones para Reproducir el Proyecto
1. Descargue o clone este repositorio en su entorno: !git clone https://github.com/GonzaloGrasso/TP-OrganizacionEmpresarial.git
2. Ejecute el script analítico principal: !python scripts/analisis_datos.py
3. Revise la consola para observar las métricas clave calculadas y la carpeta /resultados para examinar la gráfica cronológica de ventas generada.
